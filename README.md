### 🔎 Sub-Domain Enumeration Tool for Linux

A Linux-focused reconnaissance helper for authorised security assessments. The project brings together common discovery, DNS validation, HTTP probing, and virtual-host discovery steps in one workflow.

- **Core:** Bash, Linux, command-line automation
- **Tools used in the workflow:** Subfinder, Amass, PureDNS, httpx, ffuf, jq, and related recon utilities
- **Focus:** repeatable enumeration, practical output, and easier setup
- **Repository:** [efti74/Sub-Domain-Enumeration-Tool-for-Linux](https://github.com/efti74/Sub-Domain-Enumeration-Tool-for-Linux)

> Check the repository README for the current feature list, dependencies, setup instructions, and supported options.
